# site.form

Учебная адаптивная вёрстка магазина готовых сайтов. Две связанные страницы на HTML, CSS и JavaScript.

## Возможности

- Главная: первый экран, подборка сайтов, преимущества, этапы запуска, FAQ и приглашение в каталог.
- Каталог: 3 карточки, категории, поиск, сортировка, избранное, модальное окно с подробностями и сброс фильтров.
- Общие header и footer, мобильное меню, навигация между страницами.
- Светлая и тёмная темы; тема и избранное сохраняются в localStorage. При запрете хранилища интерфейс работает без сохранения.
- Адаптивность от 380 до 1440 px и шире; состояния фокуса, клавиатурное управление, поддержка reduced motion.

Примеры сайтов представлены изображениями из папки `assets`. Используются системные шрифты, внешние сервисы не требуются.

## Работа со стилями

Все стили находятся в `style.css`, который подключён к обеим страницам. Редактируйте его напрямую и обновляйте страницу в браузере. Установка зависимостей и сборка не требуются.

Цены и товары демонстрационные. Оплата, оформление заказа, скачивание шаблонов и серверная часть не реализованы. Подробные README частей задания в исходном проекте отсутствовали; реализованы требования из сообщения пользователя.

## Ручная проверка

1. Открыть обе страницы на ширинах 380, 768, 1024 и 1440 px; проверить отсутствие горизонтальной прокрутки.
2. Переключить тему, перейти в каталог и обновить страницу: тема должна сохраниться.
3. Проверить мобильное меню и переходы к секциям главной.
4. Выбрать категорию, ввести запрос, изменить сортировку и сбросить пустой результат.
5. Добавить сайт в избранное, обновить страницу и открыть категорию «Избранное».
6. Открыть карточку клавиатурой, закрыть через Escape; проверить возврат фокуса и восстановление прокрутки.
7. Раскрыть ответы FAQ мышью и клавиатурой.
